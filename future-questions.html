RESEARCH NOTES

Delayed information about the task

In a delayed-question problem, the encoding operation is chosen before the question q is revealed. The decoder may depend on q, but the encoder cannot. This asymmetry is essential to a meaningful comparison with a known-question protocol.

A complete specification gives a joint distribution of the past label and question, a memory budget, a set of admissible encodings and a scoring rule for the answer. Changing any of these can change the optimum.

RESEARCH NOTES

Two bits and one question

Let x₁ and x₂ be independent uniform bits, and let q independently select one of them with equal probability. A classical one-bit strategy can store x₁ and guess x₂ when requested. It succeeds with probability (1 + 1/2)/2 = 3/4.

The example is deliberately small enough to calculate exactly. It provides a common benchmark for comparing encodings without making claims about a new physical law.

RESEARCH NOTES

A standard quantum random-access code

A qubit may encode two bits using Bloch vectors ((−1)ˣ¹/√2, 0, (−1)ˣ²/√2). Measuring X for the first bit or Z for the second yields success (1 + 1/√2)/2 for either question, approximately 0.8536.

In this standard 2-to-1 random-access task with no additional message-correlated side information, the best classical one-bit average success is 0.75. This is a known educational comparison, not a novel QTRAC result.

Known vs
unknown.

The aim is to establish task-specific separations in memory cost or success probability.

KNOWN TASK

A tailored summary

With a known index j, store xⱼ in one classical bit; this answers the announced question with certainty.

UNKNOWN TASK

A flexible summary

For two uniform input bits and a uniform unknown question, one classical bit can achieve 3/4 average success by storing one bit and guessing the other. This is the optimal classical one-bit random-access score in this example.

CLASSICAL AND QUANTUM

Different resources

The standard two-bit-to-one-qubit random access code achieves cos²(π/8) ≈ 0.8536 using four qubit states and two measurement bases. This textbook example motivates the task; it is not an original QTRAC result.

IMPORTANT · A finite quantum advantage does not imply an advantage for every delayed-question problem.
RESEARCH NOTES

Beyond a single late question

In a temporal model, the verifier may receive evidence in stages, with the question announced before or after certain contacts. The permitted dynamics and storage between those contacts must be specified alongside the question distribution.

Upper bounds can be sought by reducing a stage to a constrained encoding problem; constructive protocols show which bounds can actually be reached. A proof must account for any fresh information the verifier receives at decoding time.

RESEARCH NOTES

The distinction from reversing time

A delayed-question code is useful because a retained state can support alternative later tests. It does not change the earlier event or transmit information backwards in time. Its success probability concerns the answer to a declared task.

QTRAC uses this distinction to motivate constrained temporal verification, where the accessibility of evidence and the time of the test both influence which questions remain answerable.
