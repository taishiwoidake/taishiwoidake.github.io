A harmless
simplification?

An ordinary compiler might simplify an expression that happens to fail for a rare negative input. Quantum software transformations also need edge-case tests.

INTUITIVE PICTURE

The everyday version

If a calculator shortcut passes familiar inputs but fails for one unusual sign or boundary case, the shortcut is not a correct replacement.

SCIENTIFIC QUESTION

The quantum version

For example, two consecutive ideal Hadamard gates equal the identity, so removing them is a valid ideal-unitary rewrite. For a general transformation, the exact contract may instead concern a distribution, observable or channel.

WHAT THIS DOES NOT CLAIM · An observed simulation difference is not sufficient without a valid oracle and the transformation's documented contract.

✳   4 / QUANTUM SOFTWARE   ✳

What makes
a bug real?

A strong report isolates the triggering input and distinguishes a real rewrite error from a bad test assumption.

REPRODUCE

Small legal input

Reduce the failing circuit to a small legal input and record its gate sequence, parameters, pass pipeline, tool version, expected semantics and actual output.

VERIFY

Correct semantics

For ideal-unitary equality up to global phase, compare U and V using a phase-invariant criterion, such as whether |tr(U†V)| equals the Hilbert-space dimension. A different contract requires a different oracle.

EXPLAIN

Root cause and scope

Use differential testing, metamorphic relations or exact reference calculations to isolate the failure. Distinguish a suspected defect, a reproducible violation and a confirmed upstream issue.

WHAT THIS DOES NOT CLAIM · This is a software-verification line, not a theorem proven from QTRAC or Ximeste–Maluna.
